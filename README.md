# Asclepius
A NLP system that analyzes prescription text or drug lists and automatically identifies dangerous drug interactions. Certain drug combinations can cause fatal reactions (heart failure, bleeding, respiratory depression). This NLP system will process unstructured text, extract drug entities, and predict interaction severity using deep learning models.

<b>Tech Stack</b>


Programming Language: Python


Libraries:


o Pandas, NumPy (data handling)

o scikit-learn (ML metrics and utilities)

o Hugging Face Transformers (BERT, RoBERTa, distilBERT)

o SpaCy (NER for drug extraction)

o PyTorch/TensorFlow (model training)


Dataset: 

DrugBank Drug Drug Interaction (DDI) Dataset

Competition:

IEEE CIS IIT - ModelX
